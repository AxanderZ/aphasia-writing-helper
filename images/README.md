# Images

Drop SVG files here with these names and they appear on the next reload;
until then each slot shows a placeholder. The paths come from
`data/categories.json` (pictures) and `data/starters.json` (starter icons).
Tab icons are `images/tab-<category>.svg`. To use PNGs, change the paths
in the JSON files.

Square artwork works best; it is shown with `object-fit: contain`.

**Sentence starters (done):** cup, help, heart, question, phone, pin

**Category tabs:** tab-people, tab-food, tab-places, tab-feelings, tab-actions

**People:** wife, husband, son, daughter, friend, doctor, nurse, me
**Food:** coffee, water, tea, juice, bread, soup, fruit, milk
**Places:** home, bathroom, bed, kitchen, outside, hospital, shop, car
**Feelings:** tired, happy, sad, pain, hungry, cold, hot, scared
**Actions:** eat, drink, sleep, go, walk, wash, sit, help-action
